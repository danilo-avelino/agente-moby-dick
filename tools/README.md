# Tools

Scripts Python para execução determinística. Cada script faz uma coisa bem definida.

## Convenções

- Um script = uma responsabilidade
- Credenciais sempre via `.env` (use `python-dotenv`)
- Outputs vão para serviços em nuvem ou `.tmp/` (temporários)
- Sempre exiba mensagens de progresso e erros claros no stdout
